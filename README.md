# Web Technology Final Project

## About the Project

This project is a web-based application developed as part of the Web Technology course. It is designed to provide an organized and user-friendly platform where different types of users can access the system and perform their respective activities through dedicated interfaces.

The application provides separate dashboards for administrators, instructors, and students. Each role has its own interface and functionality to support the overall management and operation of the system.

## Key Features

- **User Authentication:** Provides login and registration interfaces for accessing the system.
- **Admin Dashboard:** Provides an interface for administrators to manage and monitor the overall system.
- **Instructor Dashboard:** Allows instructors to access their dashboard and manage instructor-related activities.
- **Student Dashboard:** Provides students with an interface to access student-related information and activities.
- **Role-Based Interfaces:** Different dashboards are provided according to user roles.
- **Interactive User Interface:** Uses JavaScript to provide interactive functionality and improve user experience.
- **Responsive Design:** Uses CSS to create a structured and visually organized interface.

## User Roles

### 1. Admin
The Admin role is responsible for overseeing and managing the overall system.

### 2. Instructor
The Instructor role provides an interface for instructors to access and manage their academic activities within the system.

### 3. Student
The Student role provides students with access to their respective dashboard and academic-related activities.

## Technologies Used

- **HTML5** – Used to create the structure of web pages.
- **CSS3** – Used for styling, layout, and visual presentation.
- **JavaScript** – Used to implement interactive features and dynamic functionality.
- **Git & GitHub** – Used for source code management and project collaboration.

## Project Structure

The repository contains the source code of the project, organized into separate files for different dashboards, authentication pages, stylesheets, and JavaScript functionality.

## Conclusion

This project demonstrates the practical application of HTML, CSS, and JavaScript in developing a multi-role web-based application. It combines different user interfaces and functionalities into one organized system.
